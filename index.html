常见问题

1. 语音识别不出来？

  • 请确认已授权麦克风权限（设置 → sayNset → 麦克风）
  • 建议在安静环境下使用，远离电视/收音机
  • 说话时按住按钮，说完再松开
  • 录音建议时长 1-5 秒最佳

2. 闹钟不响？

  • 闹钟功能需 iOS 26+
  • 请确认已授权闹钟权限
  • iOS 系统的"勿扰模式"可能屏蔽闹钟，请检查
  • App 内闹钟列表可查看所有已设闹钟（右上角"闹钟"图标）

3. 创建提醒事项失败？

  • 请确认已授权"提醒事项"完全访问权限
  • 设置 → sayNset → 提醒事项 → 打开

4. 订阅了但功能没解锁？

  • 点击 App 主界面的"恢复购买"按钮
  • 或在系统"设置 → Apple 账户 → 订阅"中确认 sayNset 订阅状态
  • 仍无法解决？发邮件到 948425230@qq.com

5. 如何取消订阅？

  1. iPhone 设置 → Apple 账户（顶部你的名字）
  2. 订阅
  3. 找到 sayNset → 取消订阅

6. 支持哪些指令？

支持的语音指令：

  • 闹钟："5 分钟后叫我"、"明天 7 点叫我起床"
  • 日程："明天下午 3 点开会"、"周五晚上 7 点聚餐"
  • 提醒："提醒我下午给张三打电话"
  • 电话："打电话给张三"、"拨打 13800138000"
  • 短信："发短信给张三"
  • 应用："打开微信"、"打开支付宝"
  • 导航："导航到天安门"
  • 搜索："搜索天气"、"搜一下比特币价格"
  • 音乐："播放音乐"
  • 手电筒："打开手电筒"
  • 剪贴板："记住这句话"、"复制 XXX"
